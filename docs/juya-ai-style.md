# 橘鸭 AI 主题与写作排版

主要参照：用户指定的橘鸦公众号文章 https://mp.weixin.qq.com/s/fSkVo0b8poXVMKZWtjW50Q
与 https://daily.juya.uk/issues/2026-10-24/ 。

默认配置为 `juya-ai`。主题是公众号适配版，不复制站点导航、交互脚本、品牌署名或文章原句。

使用短场景导语、多条新闻概览、17px 章节标题、白底圆角摘要卡片、必要的详细段落。概览写成加粗的「…资讯概览」紧接无序列表，每条只说一个变化，手机上一行优先。数字、开放条件等细节留给摘要。章节标题宜短，首节避免重复文章主标题，窄屏上避免只剩两三个字单独占一行。
公司、关键日期、额度与限制局部加粗；简短型号和版本用行内代码，主题让短标签整体换行。长命令正常换行。不把整个段落加粗。
摘要回答发生了什么及影响谁，详情补充条件或行动建议，避免重复摘要。

图片优先使用官方公告或真实界面，放在它能解释或佐证的段落旁。按用途选排法：

- 读者必须看清的截图或图表，单张铺满正文宽度。小字密集时先裁出关键区域，水印避开文字。
- 两张需要直接对照的图，上下各放一张，用简短标签说明各自代表什么。
- 读者可以跳过的补充评测、演示等素材，才用横滑。同一事件的图可以分布在不同段落。

单图需要区分内容或补充出处时，在下一段写斜体图注。单行短图注在图片正下方居中，距图 6px；较长的图注自然换行后左对齐。紧邻正文已交代图的内容和来源时可省。解释放回相关正文，保留来源和厂商自测等边界。

横滑图组默认只在上方左对齐显示一条共同来源或用途，主题加上「横滑看 N 张」。只有某张图来源不同、信息难辨，或需说明自测、盲测等性质时，才用 Markdown 图片的 title 为该图加短标签。比例差异大的图可以拆开排，避免一张高图把整组撑高：

```markdown
:::gallery
![工作任务评测的对比图](images/benchmark.png)
![用户盲测的结果图](images/blind-test.png)
:::

*官方公告配图*
```

独立图片和图组说明均使用 13px 灰色图注；单图不显示滑动提示。
相册无需 JavaScript，不使用第三方轮播库；微信客户端仍须实机检查。
不要用山水、装饰插画或无关照片凑数；多图不代表每条新闻都需要插图。

正文外层在微信产物中不指定底色和正文色，继承阅读页配色。章节标题条、摘要卡片和型号标签用半透明暖色打底，小字继承正文色后降低不透明度。截图和图表保留原色。

本地预览随系统明暗切换。浅色预览使用暖白底，深色预览使用近黑底、暖白正文、暖深灰标题条和卡片。暗色图注与来源名保持清晰，网址稍弱。微信实际效果需在客户端预览确认。
参考来源用 `### 参考链接` 加无序链接列表，转换时合并正文链接、去重，保留一组灰色小字列表收尾。来源名称用稍重的字重，完整网址保持常规灰字且同条只出现一次。默认不追加创作页脚，来源账本仍保留核对记录。

每篇公众号文章默认在参考列表前保留两行固定互动文案，各出现一次：

> 觉得这期有用，欢迎点赞、收藏。
>
> 点击下方名片，关注更多 AI 与新工具资讯。

两行共用浅暖色提示块和左侧强调线：外层 `margin:22px 0 18px;padding:14px 16px;background:rgba(145,115,76,0.10);border-left:4px solid #c96442;border-radius:12px;color:inherit`；第一行 17px、字重 700、行高 1.75，第二行 16px、字重 600、行高 1.8、上间距 6px。文字继承阅读页颜色，不能按普通灰色小字弱化。约 390px 窄屏检查醒目程度及有无重叠。

名片放在提示块与参考列表之间。草稿预留名片位置；接口无法插入原生名片时保留第二行，并在交付时说明需在微信编辑器补入，不能自动删掉关注文案。成稿、预览和草稿回读均核对两行完整。
