# 橘鸭 AI 主题与写作排版

主要参照：用户指定的橘鸦公众号文章 https://mp.weixin.qq.com/s/fSkVo0b8poXVMKZWtjW50Q
与 https://daily.juya.uk/issues/2026-10-24/ 。

默认配置为 `juya-ai`。主题是公众号适配版，不复制站点导航、交互脚本、品牌署名或文章原句。

使用短导语、多条新闻概览、逐条标题、白底圆角摘要卡片、必要的详细段落。
公司、关键日期、额度与限制局部加粗；型号和版本用行内代码。不把整个段落加粗。
摘要回答发生了什么及影响谁，详情补充条件或行动建议，避免重复摘要。

图片优先使用对应事件的官方公告或真实界面，保留来源。两张及以上相关图用原生横向滚动相册：

```markdown
:::gallery
![官方发布图](images/announcement.png)
![产品界面](images/interface.png)
:::
```

自动生成“左右滑动查看 · 共 2 张”。单图按普通图片展示，不显示滑动提示。
相册无需 JavaScript，不使用第三方轮播库；微信客户端仍须实机检查。
不要用山水、装饰插画或无关照片凑数；多图不代表每条新闻都需要插图。

主题保留正文标题，暖白背景随正文容器一起发布，而不是仅在本地预览显示。
默认不追加创作页脚，来源账本仍保留核对记录。
